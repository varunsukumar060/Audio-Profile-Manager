# Audio Profile Manager v0.5.0

**Development release — Fedora 44 RPM**

## What's included

- Safer profile persistence with validation and atomic JSON writes.
- Individual profile import/export and full profile backup/restore.
- Per-output and master volume settings.
- System tray quick controls for switching profiles, stopping routing, and reopening the main window.
- Desktop global shortcut registration.
- Smart device-aware rules for profile suggestions and confirmed automatic switching.
- Explicit per-application audio stream routing.
- Fedora RPM packaging and automated packaging checks.

## Verification

Local acceptance checks previously reported passing results for tray controls, global shortcuts, device rules, and application routing. The RPM release workflow additionally runs unit tests, desktop-entry validation, and Python bytecode compilation.

## Safety notes

- This is the isolated development package, not a replacement for an existing production installation.
- Saved configuration and runtime cache use separate development paths.
- Applying or stopping a profile changes active audio routing in the current user session. Avoid running development and production applications with the same profile name simultaneously.
- Importing a profile or restoring a backup saves configuration; it does not automatically apply profiles.

## Fedora package

The tag-triggered release workflow uploads the Fedora 44 RPM and its SHA-256 checksum after a successful build. The expected RPM filename is `audio-profile-manager-dev-0.5.0-2.fc44.noarch.rpm`.
